# Projeto de Análise Imobiliária de Brasília

## Sobre o Projeto

Este projeto apresenta uma análise detalhada do mercado imobiliário de Brasília, capital federal do Brasil. O estudo é baseado em um extenso conjunto de dados de imóveis à venda em diferentes regiões administrativas de Brasília, incluindo informações sobre preços, características e localização geográfica.

## Conjunto de Dados

O projeto utiliza um rico banco de dados de propriedades imobiliárias contido no arquivo `brasilia.json`, que inclui mais de 40.000 registros de imóveis com as seguintes informações:

- **Dados básicos**: ID, endereço, valor, área, IPTU e condomínio
- **Características**: Número de quartos, vagas de garagem, banheiros
- **Localização**: Bairro, latitude e longitude
- **Comodidades**: Presença de piscina, academia, playground, quadra de esporte, etc.
- **Tipo de imóvel**: Casas, apartamentos, flats, etc.
- **Fonte da listagem**: Links para anúncios no Zap Imóveis

## Regiões Cobertas

O dataset abrange diversas regiões de Brasília, incluindo:

- Asa Sul
- Asa Norte
- Ceilândia Sul
- Ceilândia Norte
- Candangolândia
- Cruzeiro Novo
- Areal (Águas Claras)
- Brazlândia
- Alto da Boa Vista (Sobradinho)
- Entre outras áreas

## Tecnologias Utilizadas

- **JSON**: Armazenamento estruturado dos dados imobiliários
- **HTML**: Interface web para visualização das análises
- **Geolocalização**: Dados de coordenadas geográficas para mapeamento dos imóveis

## Como Utilizar

1. Clone este repositório
2. Abra o arquivo `index.html` em um navegador web
3. Explore os dados e análises disponíveis sobre o mercado imobiliário de Brasília

## Potenciais Aplicações

- Análise de preços médios por região
- Comparação de características de imóveis entre diferentes bairros
- Mapeamento da distribuição geográfica de propriedades
- Identificação de tendências no mercado imobiliário de Brasília
- Estudo sobre a relação entre comodidades e valores dos imóveis

## Fonte dos Dados

Os dados foram coletados do portal Zap Imóveis, como indicado nas URLs associadas a cada listagem no arquivo `brasilia.json`.
